# Interior scene v3

`LayoutGraph` remains the source of walls, rooms, openings, stairs and floors. The reconstruction worker exports the structural `model.glb` with stable metre-space UVs. `scene.json` v3 adds `materials`, `surface_assignments`, `furniture_assets`, `furniture_instances`, `furnishing_diagnostics`, `design_diagnostics`, `asset_library_version` and `interior_library_version`. Older v1/v2 scenes retain their original viewer colors.

Floor UVs are world X/Z metres; wall UVs are distance along the wall and height in metres. A material's `repeat` is its physical width and height in metres. The viewer applies reciprocal repeat to color textures, marks them sRGB, and uses metallic-roughness materials. Failed texture requests fall back to solid color. The first release assigns one finish to a whole shared wall; the contract reserves `side` for future side-specific finishes.

Furniture assets live at `/interiors/models/*.glb` and are shared across properties. Metadata records dimensions, floor-centered pivot, local +Z forward direction, room compatibility, preferred relation and clearance. The worker tests full Shapely footprints against room boundaries, other furniture, opening zones and stair zones. It records placement or omission reasons. The viewer loads each unique GLB through the shared `useGLTF` cache and isolates failures per item. Furniture is absent from the shell GLB.

`room_interior_settings` stores only per-room overrides under organization RLS. The global catalog is read-only code and static assets. The editor can select standard/unfurnished, choose floor and wall finishes, remove a furniture type, or restore defaults. These overrides are included in private preview and public tour payloads and applied without changing topology. A new model generation reads them too. Apply `20261025000000_room_interiors.sql` before deploying the updated frontend, worker and `public-tour` function.

## Asset preparation

Run `python services/reconstruction/tools/build_interior_assets.py` with `PYTHONPATH=services/reconstruction`. The script is the editable source for the initial first-party library. An externally authored replacement must use metre units, Y up, floor-centered origin, +Z forward, PBR materials, valid UVs, no cameras/lights, stable node names and a declared bounding box within 5 cm of its GLB bounds. Keep source licenses and authoring files with the asset; do not copy arbitrary Internet models. Compress large future textures before adding them; these first-party 256 px runtime textures total about 318 KB.

Run `npm run validate:interiors` for metadata and official Khronos glTF validation. The catalog now has eleven project originals and twelve approved Sweet Home 3D BlendSwap CC0 conversions. The imported GLBs total 4,464,296 bytes. The reference shell is 24,824 bytes, has 344 triangles and 32 geometry nodes. The fixed reference has twelve furniture instances. Its texture catalog contains seven PNGs and the viewer loads them only in 3D mode. Asset-specific draw calls and FPS depend on the browser and GPU; the development-only `/interior-reference` page displays measured FPS, calls and rendered triangles. See `INTERIOR_ASSET_PIPELINE.md` and `INTERIOR_ASSET_PROVENANCE.md` for the second library version.

## Reference and tests

Regenerate the four-room reference with `python services/reconstruction/tools/build_reference_interior.py` using the same `PYTHONPATH`. It has living, bedroom, dining and office rooms, oak and dark wood floors, painted walls, one wood accent wall, windows, doors and an entrance. Run the Python geometry and interior tests. The three fixed top-down image baselines in `services/reconstruction/tests/interiors/baselines` cover whole-level, living room and bedroom placement plus metre-scaled floor textures. To inspect a deliberate visual change, run `python services/reconstruction/tools/render_interior_reference.py --update` and review the changed PNGs. These deterministic projections complement manual WebGL PBR inspection; they do not certify shader output on every GPU.

Release checks: `npm run typecheck`, `npm run lint`, `npm run build`, `node scripts/test-topology.mjs`, `python -m pytest services/reconstruction/test_geometry.py services/reconstruction/test_interiors.py -q`, and `npm run validate:interiors`. Verify private preview, published `/tour/:slug`, and its iframe after migration and worker deployment. The source code loads the scene and furniture only when 3D mode is selected; Photos and Floor Plan do not fetch them.
